# Qubes xfwm4

This repo holds the [Qubes OS](https://www.qubes-os.org) packaging of
[xfwm4](https://docs.xfce.org/xfce/xfwm4/start), the Xfce window manager. On top
of the upstream sources it carries Qubes patches that draw each window's
decoration (border and title) in the color of the qube it belongs to, and
prefix the title with the qube's name, so you can tell at a glance which qube a
window comes from.

For what the window colors mean, see
[Color & Security](https://doc.qubes-os.org/en/latest/introduction/getting-started.html#color-security).
